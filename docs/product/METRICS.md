# Discovery Metrics

## Primary signal

Users who process real, non-sensitive data and request a complete diagnostic report.

## Funnel

1. Qualified landing-page visit.
2. Validator started.
3. Validation completed.
4. Report requested.
5. Paid-plan intent.
6. Payment completed in a future approved phase.

## Initial thresholds after 300 qualified visitors

| Metric | Weak | Promising | Strong |
|---|---:|---:|---:|
| Validator started | < 5% | 10–15% | > 20% |
| Validation completed | < 3% | 8–12% | > 15% |
| Report requested | < 2% | 5–8% | > 10% |
| Paid-plan click | < 1% | 3–5% | > 7% |
| API access request | 0 | 3–5 | > 8 |

Vanity metrics such as impressions and raw page views cannot authorize product development or spending on their own.

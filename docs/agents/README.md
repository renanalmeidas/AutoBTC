# Agent Catalog

Agents are versioned responsibility contracts, not identities with unrestricted access.

| Agent | Primary output |
|---|---|
| Product Owner | Prioritized outcome and backlog |
| Scrum Master | Flow, blockers and cadence |
| Business Rules | Versioned domain rules |
| Architect | ADRs and boundaries |
| Backend | Domain and APIs |
| Frontend | Safe user experience |
| Payments | Product billing design |
| QA/Security | Test evidence and risk review |
| Brand/Creative | Brand system and creative variants |
| Paid Traffic | Measurable campaign proposal |
| Analytics/CRO | Events, funnel and experiment analysis |
| Budget/Compliance | Spend and claim gates |

Use `AGENT_CONTRACTS.md` for detailed inputs, outputs and prohibitions. One person or model may perform multiple roles, but approvals must still be recorded separately.

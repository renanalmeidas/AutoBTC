# Approval Matrix

| Change | Required reviews | Final authority |
|---|---|---|
| Product hypothesis | Product Owner, Analytics | Owner |
| Business rule | Business Rules, QA | Owner/Product Owner |
| Architecture | Architect, Security | Owner or delegated maintainer |
| Application code | Code Review, QA | Human maintainer |
| Payment feature | Payments, Security, Compliance, Business Rules | Owner |
| Brand asset | Brand/Creative, Product | Owner |
| Paid campaign proposal | Paid Traffic, Analytics, Brand, Compliance, Budget Controller | Owner |
| Real expenditure | All campaign gates | Owner manually pays |
| Budget increase | Budget Controller impact analysis | Owner |

Agent consensus is advisory. It never becomes financial authorization.
